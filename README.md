# Internship Static Webpage

## About the Project
This project is a responsive static webpage created using HTML5 and CSS3 as part of my Week 1 internship task, **“Transforming Wireframes into Static Web Pages.”**

The webpage showcases an internship platform layout with a navigation bar, hero section, internship cards, an About section, and a footer.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Web Design

## Features
- Clean and simple user interface
- Navigation menu
- Internship opportunity cards
- Responsive layout for desktop, tablet, and mobile screens
- Semantic HTML elements
- Organized and maintainable CSS

## Project Structure
```text
internship-project/
├── index.html
├── style.css
└── README.md
```

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
